# Beta_04 配置手册

# 第一部分：科目映射规则

## 🎯 映射原则

Beta_04 分析表的数据来源于三个原始数据表：
- **balance**（资产负债表）

映射规则定义了 Beta_04 中每个字段对应原始表中的哪个科目。

## 💡 第三部分：盈利结构分析（10项）

盈利结构分析展示了从主营收入到自由现金流的完整计算过程。

| 序号 | 指标名称 | 计算公式 | 说明 |
|-----|---------|---------|------|
| 1 | 主营收入 | =引用「主营收入」 | 从损益表数据引用 |
| 2 | 主营成本 | =引用「主营成本」 | 从损益表数据引用 |
| 3 | 费用 | =引用「费用」 | 从损益表数据引用 |
| 4 | 损耗 | =引用「损耗」 | 从损益表数据引用 |
| 5 | 其他收益 | =引用「其他收益」 | 从损益表数据引用 |
| 6 | 现金收益 | =引用「现金收益」 | 从损益表数据引用 |
| 7 | 利息支出 | =引用「利息支出」 | 从损益表数据引用 |
| 8 | 财务费用 | =引用「财务费用」 | 从损益表数据引用 |
| 9 | 所得税 | =引用「所得税」 | 从损益表数据引用 |
| 10 | **业务利润** | **=主营收入 - 主营成本 - 费用 + 损耗 + 其他收益 + 现金收益 - 利息支出 - 财务费用 - 所得税** | 核心业务利润 |
| 11 | 股权收益 | =引用「股权收益」 | 从损益表数据引用 |
| 12 | 其他业务利润 | =其他业务收入 - 其他业务成本 | 其他业务净利润 |
| 13 | 营业外利润 | =营业外收入 - 营业外成本 | 营业外净利润 |
| 14 | **净利润** | **=业务利润 + 股权收益 + 其他业务利润 + 营业外利润** | 归属于母公司的净利润 |
| 15 | 分红 | =引用「股息分红」 | 从资产负债表数据引用 |
| 16 | **利润留存** | **=净利润 - 分红** | 留存利润 |
| 17 | 折旧摊销 | =引用「折旧摊销」 | 从损益表数据引用 |
| 18 | CAPEX | =引用「资本开支」 | 从损益表数据引用 |
| 19 | **自由现金流 (FCF)** | **=利润留存 + 折旧摊销 - CAPEX** | 自由现金流 |

**Excel 公式示例**（假设数据在 C 列）：
```excel
业务利润 (C59) = C50 - C51 - C52 + C53 + C54 + C55 - C56 - C57 - C58
净利润 (C63) = C59 + C60 + C61 + C62
利润留存 (C65) = C63 - C64
自由现金流 (C68) = C65 + C66 - C67
```

经营指标用于评估公司的盈利能力和运营效率。

| 指标名称 | 计算公式 | 说明 |
|---------|---------|------|
| 毛利率 | =(主营收入 - 主营成本) / 主营收入 | 毛利率 |

| 管理费率 | =管理费用 / 主营收入 | 管理费用率 |
| 净利率 | =业务利润 / 主营收入 | 净利率 |

### 营运能力指标（4项）

| 指标名称 | 计算公式 | 说明 |
|---------|---------|------|
| 应收占比 | =应收 / 主营收入 | 应收账款占收入比 |

## 🎓 第七部分：ROE 分解（4项）

ROE（净资产收益率）分解采用杜邦分析法，将 ROE 分解为三个驱动因素。

| 指标名称 | 计算公式 | 说明 |
|---------|---------|------|
| ROE | =业务利润 / 权益 | 净资产收益率 |
| 净利率 | =业务利润 / 主营收入 | 盈利能力 |
| 资产周转率 | =主营收入 / 资产 | 运营效率 |
| 权益乘数 | =资产 / 权益 | 财务杠杆 |

**杜邦公式**：
```
ROE = 净利率 × 资产周转率 × 权益乘数
    = (业务利润/主营收入) × (主营收入/资产) × (资产/权益)
    = 业务利润 / 权益
```

**Excel 公式示例**（假设数据在 C 列）：
```excel
ROE (C115) = C59 / C14
净利率 (C116) = C59 / C28
资产周转率 (C117) = C28 / C2
权益乘数 (C118) = C2 / C14
```

## 💎 第八部分：估值指标（5项）

估值指标用于评估公司的投资价值。

| 指标名称 | 计算公式 | 说明 |
|---------|---------|------|
| DPS（每股股息） | =股息分红 / 股本 | 每股股息 |
| EPS（每股收益） | =业务利润 / 股本 | 每股收益 |
| FPS（每股自由现金流） | =自由现金流 / 股本 | 每股自由现金流 |
| PE（市盈率） | =股价 / EPS | 市盈率 |
| 股息率 | =DPS / 股价 | 股息率 |

**Excel 公式示例**（假设数据在 C 列）：
```excel
DPS (C120) = C17 / C26
EPS (C121) = C59 / C26
FPS (C122) = C68 / C26
PE (C126) = C124 / C121  # C124 是手动输入的股价
股息率 (C128) = C120 / C124
```

**注意**：
- 股价（最高价、最低价）需要手动输入
- PE 和股息率会根据输入的股价自动计算

## 📝 使用说明

### 数据准备步骤

1. **准备原始数据表**
   - 创建 balance、损益现金流、收入成本 三个工作表
   - 按照标准科目名称填写数据
   - 确保年份格式正确（balance: 2024.12.31, 其他: 2024）

2. **运行数据提取**
   ```bash
   python3 generate_beta04_v2.py 你的公司.xlsx
   ```

3. **验证数据**
   - 检查资产负债表数据是否正确提取
   - 检查损益表数据是否正确提取
   - 验证盈利结构分析的计算逻辑

4. **手动输入股价**
   - 在估值指标部分手动输入年度最高价和最低价
   - PE 和股息率会自动计算

### 公式验证清单

- [ ] 业务利润 = 主营收入 - 主营成本 - 费用 + 损耗 + 其他收益 + 现金收益 - 利息支出 - 财务费用 - 所得税
- [ ] 净利润 = 业务利润 + 股权收益 + 其他业务利润 + 营业外利润
- [ ] 自由现金流 = 利润留存 + 折旧摊销 - CAPEX
- [ ] ROE = 净利率 × 资产周转率 × 权益乘数
- [ ] 资产 ≈ 负债 + 权益（平衡检查）

## 🔧 常见问题

### Q1: 如何适配不同公司的数据？
A: 确保原始数据表使用标准科目名称，系统会自动识别和提取数据。

### Q2: 如果某个科目不存在怎么办？
A: 系统会将其视为 0，不会影响其他计算。
